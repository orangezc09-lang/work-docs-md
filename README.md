## 如何使用

1. 复制所需模板，另存为自己的工作文档。
2. 手工填写时替换方括号内容；缺少的信息写“待确认”。
3. 使用 AI 时，将同一文件中的“空白模板”和“AI 整理指令”一起复制到对话，再贴入脱敏后的材料。
4. 核对人名、数字、日期、完成状态和决定。AI 输出是草稿，负责人和截止时间须由相关人员确认。
5. 删掉不适用的行，保留关键待定问题，再分享。

记事本或常见 Markdown 编辑器均能打开。部分文档软件的表格显示可能不同，可按需要改为列表。

## 整理原则

- 开始执行、初稿完成和验收通过分开记录。
- 建议不自动变成决定，未确认安排不自动变成承诺。
- 缺少事实就保留缺口，不补造数字、链接或成果。

分享或上传到外部 AI 前，去掉密码、密钥、客户身份信息和公司不允许外传的内容。
